# v0.9.0 Word preservation corpus

This directory contains deterministic, fictional engineering fixtures for the
v0.9.0 Word preservation matrix. They are not customer documents or adoption
evidence.

`manifest.json` declares each operation, category, allowed changed part,
byte-protected part, semantic assertion, and refusal boundary. `report.json` is
generated by the same tests that execute the operations. The two result `.docx`
files are inspectable diff artifacts produced from `rich-word-features.docx`.

Run the focused tests without Microsoft Office:

```powershell
dotnet test tests/OfficeAgent.Tests/OfficeAgent.Tests.csproj `
  --configuration Release `
  --filter "FullyQualifiedName~WordPreservationEvidenceTests"
```

Regenerate the fixture, result packages, and report only when deliberately
updating this evidence:

```powershell
$env:OFFICEAGENT_WORD_PRESERVATION_OUTPUT = `
  'tests/OfficeAgent.Tests/Corpus/v0.9.0/word-preservation'
dotnet test tests/OfficeAgent.Tests/OfficeAgent.Tests.csproj `
  --configuration Release `
  --filter "FullyQualifiedName~Generate_word_preservation_fixture"
Remove-Item Env:OFFICEAGENT_WORD_PRESERVATION_OUTPUT
```

Review the manifest and generated diff artifacts before accepting changed
hashes. The generator uses fixed inputs and time, so unexplained drift is a
failure to investigate, not a reason to weaken an assertion.

These tests verify Office 2019 schema validity, exact bytes for protected
package parts, deliberate semantics inside allowed changed parts, and no-write
refusals. The report records one separate Word opening observation. It does not
claim rendering parity or completed native accept/reject coverage. The complete
native Word matrix belongs to the v1.0 compatibility work.
